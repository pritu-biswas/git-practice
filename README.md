# git-practice
A beginner-friendly repository for practicing Git and GitHub commands, branching, commits, pull requests, and stash.

## What is Git?
Git is a version control system used to track changes in files.

## What is GitHub?
GitHub is a cloud-based platform for hosting and managing Git repositories.

## Basic Git Commands

- git init: Initialize a Git repository.
- git status: Check the current status.
- git add: Stage changes.
- git commit: Save changes.
- git push: Upload changes to GitHub.
- git pull: Download updates from GitHub.
- git clone: Copy a remote repository.
- git branch: List branches.
- git switch: Switch branches.
- git stash: Temporarily save uncommitted changes.

## Git Workflow

1. Create a branch.
2. Make changes.
3. Stage changes.
4. Commit changes.
5. Push the branch.
6. Create a Pull Request.
